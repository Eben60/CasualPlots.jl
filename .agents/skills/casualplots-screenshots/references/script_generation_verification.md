# Script Generation Verification & Size Factor Calibration

This reference document describes how to verify standalone Julia scripts generated by `CasualPlots.jl` against Electron GUI screenshots, how to calibrate the plot pane size factor, and how to measure corner coordinates to ensure 1:1 pixel alignment.

For the primary screenshot generation and interaction workflow, see [Agentic Screenshots](../SKILL.md).

---

## 1. Overview & Verification Purpose

`CasualPlots.jl` can generate standalone Julia scripts reproducing the current GUI plot using declarative `AlgebraOfGraphics.jl` pipelines and `Makie.jl` themes. The standalone plot verification workflow verifies that:

1. **Syntactic and Runtime Validity**: Auto-generated scripts execute cleanly without errors in standalone Julia environments.
2. **Visual Fidelity**: Plots rendered by generated scripts match the GUI plot pane rendering semantically and pixel-wise (SSIM > 0.996).
3. **Theme Isolation**: Generated scripts explicitly reset themes (`set_theme!()`, `set_aog_theme!()`, etc.) so that sequential execution does not cause theme pollution across runs.

While user-facing scripts generated from the GUI default to a standard `fig_size = (800, 600)`, scripts generated during screenshot testing use calibrated dimensions `fig_size = (808, 610)` to match the exact Electron floating window canvas 1:1.

---

## 2. Size Factor Calibration & Plot Pane Measurement

### Why Calibration is Needed

In the Electron GUI (`1200 × 960` window), the plot pane is hosted in a `BonitoWidgets.FloatingWindow`. Due to window chrome, padding, control panel width, and tab borders, the inner WebGL canvas is:
- **Width**: `808 px`
- **Height**: `610 px`
- **Top-left offset in screenshot**: `(x = 362, y = 40)`

If a standalone plot is rendered at `(800, 600)`, the inner axis frame is slightly smaller than the GUI canvas (`574 × 506 px` vs `582 × 516 px`, a ~1.4% difference). To achieve a 1:1 pixel match for SSIM comparison without interpolation or scaling artifacts, standalone figures are rendered at `808 × 610`.

---

### Calibration Protocol via Corner Coordinates

The reference test case used for calibration is `xy_source_selection`:
- **Screenshot**: `docs/src/Screenshots/xy_source_selection.png` (`1200 × 960` px)
- **Standalone Plot**: `tmp/genplots/xy_source_selection_fig.png` (`808 × 610` px)

#### 1. Measure the Frame Corners on the Screenshot

Locate the outer corners of the black rectangular plot frame (axis spine) on the screenshot:
- **Top-left corner**: `x = 430, y = 74`
- **Bottom-right corner**: `x = 1012, y = 590`
- **Frame Width**: `1012 - 430 = 582 px`
- **Frame Height**: `590 - 74 = 516 px`

#### 2. Measure the Frame Corners on the Standalone Plot

Locate the same corners on the standalone figure rendered at `808 × 610`:
- **Top-left corner**: `x = 69, y = 35`
- **Bottom-right corner**: `x = 651, y = 551`
- **Frame Width**: `651 - 69 = 582 px`
- **Frame Height**: `551 - 35 = 516 px`

#### 3. Calculate the Size Factor

$$\text{Scale}_X = \frac{W_{\text{screenshot}}}{W_{\text{plot}}} = \frac{582}{582} = 1.000$$

$$\text{Scale}_Y = \frac{H_{\text{screenshot}}}{H_{\text{plot}}} = \frac{516}{516} = 1.000$$

Both scale factors are **1.0 (exact 1:1 match)**. The axis tick marks, labels, titles, and plot markers align identically without any font scaling or stretching.

#### 4. Calculate the Cropping Coordinates

The canvas offset is the difference between the corner positions:

$$\Delta x = x_{\text{shot}} - x_{\text{plot}} = 430 - 69 = 361 \text{ px} \implies \text{cols} = 362 : (362 + 808 - 1) = 362 : 1169$$

$$\Delta y = y_{\text{shot}} - y_{\text{plot}} = 74 - 35 = 39 \text{ px} \implies \text{rows} = 40 : (40 + 610 - 1) = 40 : 649$$

Therefore, the exact bounding box for the plot canvas in `1200 × 960` screenshots is:
- **`rows = 40:649`** (height = 610 px)
- **`cols = 362:1169`** (width = 808 px)

### How to Recalibrate on Future GUI Layout Changes

If the GUI layout, floating window styles, or window dimensions change in future versions:

1. **Generate Reference Files**:
   ```julia
   using Pkg; Pkg.activate("test/AgenticTesting")
   using AgenticTesting
   run_screenshot_generator(generate_xy_source_screenshot; makescript = true, scriptfile = "tmp/genscripts/xy_source_selection.jl")
   ```
2. **Execute Script at Current Default Size**:
   Render the plot to `tmp/genplots/xy_source_selection_fig.png`.
3. **Measure Coordinates in Julia**:
   ```julia
   using FileIO, Colors
   img_shot = RGB.(FileIO.load("docs/src/Screenshots/xy_source_selection.png"))
   img_plot = RGB.(FileIO.load("tmp/genplots/xy_source_selection_fig.png"))

   # Find frame boundaries by thresholding dark axis spine pixels:
   # For example, inspect horizontal and vertical cross-sections where Gray(c) < 0.1
   ```
4. **Compare Dimensions**:
   - If $W_{\text{shot}} \ne W_{\text{plot}}$ or $H_{\text{shot}} \ne H_{\text{plot}}$, adjust `fig_size` in the screenshot generators (`capture_gui_screenshot`) by the difference:
     $$W_{\text{new}} = W_{\text{plot}} + (W_{\text{shot}} - W_{\text{plot}})$$
     $$H_{\text{new}} = H_{\text{plot}} + (H_{\text{shot}} - H_{\text{plot}})$$
5. **Update Crop Range**:
   Update `crop_rows` and `crop_cols` in `crop_screenshot_plot` ([`test/AgenticTesting/src/image_comparison.jl`](file:///Users/elk/Julia/1-Registered-Packages/CasualPlots.jl/test/AgenticTesting/src/image_comparison.jl)).

## 3. Verification Workflow (`run_screenshots_with_scripts.jl`)

### Running Verification

Execute the standalone runner script:

```julia
include("test/AgenticTesting/scripts/run_screenshots_with_scripts.jl")
```

The runner accepts the `verify_against` keyword argument:
```julia
using Pkg; Pkg.activate("test/AgenticTesting")
using AgenticTesting

# 1. Verify against golden reference screenshots in docs/src/Screenshots/<name>.png (default):
run_screenshots_with_scripts(; verify_against = :golden)

# 2. Verify against just-produced screenshots in docs/src/Screenshots/tmp/<name>_NN.png:
run_screenshots_with_scripts(; verify_against = :produced)

# 3. Verify against both golden and produced:
run_screenshots_with_scripts(; verify_against = :both)
```

### Execution Pipeline

The runner performs the following steps automatically:

```
┌────────────────────────────────────────────────────────┐
│ 1. Run Screenshot Generators (makescript=true)         │
│    Saves scripts to tmp/genscripts/<stem>.jl (808×610) │
└──────────────────────────┬─────────────────────────────┘
                           │
┌──────────────────────────▼─────────────────────────────┐
│ 2. Post-Process Scripts                                │
│    Uncomments cp_load_data & cp_create_plot            │
│    Appends save("tmp/genplots/<stem>_fig.png", fg)     │
└──────────────────────────┬─────────────────────────────┘
                           │
┌──────────────────────────▼─────────────────────────────┐
│ 3. Execute Scripts Standalone                          │
│    Runs in pkgdir(CasualPlots) with WGLMakie + AoG     │
└──────────────────────────┬─────────────────────────────┘
                           │
┌──────────────────────────▼─────────────────────────────┐
│ 4. SSIM Comparison (compare_screenshot_plot_ssim)      │
│    Crops canvas (rows 40:649, cols 362:1169)           │
│    Evaluates SSIM >= 0.98 (macOS) / 0.90 (Linux)       │
└────────────────────────────────────────────────────────┘
```

## 4. API Reference

### `crop_screenshot_plot`

```julia
crop_screenshot_plot(screenshot::AbstractArray; rows = 40:649, cols = 362:1169) -> AbstractArray
crop_screenshot_plot(screenshot_path::AbstractString; rows = 40:649, cols = 362:1169) -> Matrix{RGB}
```

Crops the `808 × 610` plot canvas from a full `1200 × 960` CasualPlots GUI screenshot.

### `compare_screenshot_plot_ssim`

```julia
compare_screenshot_plot_ssim(
    screenshot_path::AbstractString,
    plot_path::AbstractString;
    threshold::Real = Sys.isapple() ? 0.98 : 0.9,
    crop_rows = 40:649,
    crop_cols = 362:1169,
) -> (; passed::Bool, score::Union{Real, Missing})
```

Crops the screenshot canvas and computes the SSIM index against the standalone rendered figure. Returns `passed::Bool` and `score`.
- **Expected Score**: `> 0.996` (average ~0.9984).
- If sizes differ slightly, automatically takes the minimum overlapping window without interpolation.
