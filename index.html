CasualPlots.jl

CasualPlots.jl is a GUI-based plotting application for Julia. It is positioned in the middle ground between purely script-based plotting and standalone GUI plotting tools.

The package is intended for experimental scientists, engineers, and casual Julia users who require fast visual exploration of 2D data without having to memorize syntax for common plot customizations.

What it is not: In no way is the intention to compete with any “serious” tools in terms of feature scope – not with standalone behemoths like commercial Origin or free Veusz, nor with Julia graphic packages like Makie.jl or Plots.jl.

The main feature of CasualPlots.jl is the combination of a GUI for data visualization, both as table and plot, with direct access to the variables in the Julia REPL session. You can inspect or hot-patch workspace variables and loaded file data in the REPL—or reload modified files from disk—and click (Re-)Plot to update the visualization. Once you create and format a plot, it can be saved, or CasualPlots can generate a standalone Julia script that reproduces the exact visualization. You can then polish that script to produce a publication-ready figure or integrate the code directly into a data processing pipeline.

Features

  • Data Sources & Live Reloading:
    • Julia Main workspace variables (Vectors, Matrices, and DataFrames). Unitful data are welcome.
    • External files on disk in CSV/TSV and XLSX format, with live REPL access via cp_file_df.
    • Hot-patching support: modify variables in Main in the REPL and click (Re-)Plot to refresh the plot and table with automatic structural validation.
  • Plot Types:
    • Common 2D plot types: Scatter, Lines, Line+Symbol, and BarPlot (supporting vertical or horizontal orientation, and dodged or stacked modes).
    • Dataset grouping by color or geometry (marker shape or line style).
  • Data Table Representation: Displays the selected dataset and row range immediately in a scrollable table.
  • Script Generation: Generates standalone Julia scripts replicating plots configured in the GUI using AlgebraOfGraphics and Makie.
  • Saving Plots: Exports static figures directly from the GUI as PNG, SVG, or PDF.

Software Stack

  • GUI: Bonito.jl and BonitoWidgets.jl.
  • Plotting Pipeline: AlgebraOfGraphics.jl (commonly abbreviated to AoG), and Makie.jl (WGLMakie.jl for interactive display and CairoMakie.jl for file export).

How To Use

Installation

CasualPlots.jl is a registered package. It requires Julia v1.10 or higher.

Note

Because the package pulls in roughly 300 transitive dependencies, avoid installing it into your default global environment to prevent potential version conflicts.

# Not recommended:

(@v1.13) pkg> add CasualPlots

Instead, it is better to install it directly into your project environment/workspace. Alternatively, install it into a shared environment and load it anywhere using ShareAdd.jl:

julia> using ShareAdd

julia> @usingany CasualPlots

@usingany loads the package from any shared environment if found. If not, it first prompts to install it into a shared environment of your choice.

Launching the GUI

CasualPlots.jl creates a Bonito GUI application that can display in a standalone Electron.jl window, a web browser, or the VS Code plot pane.

Default Display (which may be plot pane or browser)

julia> using CasualPlots

julia> app = casualplots_app()

julia> display(app)

julia> close(app)  # close the app when finished

Serving to a Web Browser

julia> using Bonito

julia> app = casualplots_app()

julia> server = Bonito.Server(app, "127.0.0.1", 8000)
Server:
  isrunning: true
  listen_url: http://localhost:8000
  online_url: http://localhost:8000
  http routes: 1
    / => App
  websocket routes: 0

Open a browser and navigate to http://localhost:8000 (or the fallback port shown in the terminal message if port 8000 is occupied).

Standalone Electron Window

julia> app = casualplots_app()

julia> Ele.serve_app(app)

The author prefers Electron when using the package.

See usage/testing examples in the scripts in the src/scripts folder of the package.

Note
  • External Files (CSV and XLSX): File import uses package extensions, so you must run using CSV and/or using XLSX before starting the GUI if you plan to load files from disk.
  • TTFP: Even on a fast computer, there may be a noticeable delay on first plot creation, colloquially known to Julia users as the "Time To First Plot" (TTFP). Please be patient on the first use. Subsequent replotting is fast.

For a complete walkthrough of selecting data, formatting plots, customizing live figures from the REPL, and exporting plots or scripts, see:

  • Tutorial — Step-by-step guide to all GUI tabs and workflows.
  • Script Generation — How to generate and customize standalone Julia plotting scripts.
  • Introduction to AlgebraOfGraphics — A practical guide to AlgebraOfGraphics.jl for customizing generated scripts.

Exported Entities

CasualPlots.casualplots_app — Method
casualplots_app()

Create and return the main CasualPlots application.

This function assembles the complete interactive plotting application with:

  • Data source selection (X and Y variables)
  • Plot formatting controls (plot type, legend)
  • Label text fields (X-axis, Y-axis, title)
  • Real-time plot and table display
  • Tabbed interface for organized controls

CasualPlots.CasualPlotApp — Type
CasualPlotApp

A wrapper around Bonito.App that also holds the application state. This prevents the state from being garbage collected prematurely and allows programmatic interaction with the UI via app.state.

source
CasualPlots.cp_figure — Constant
cp_figure

The active global Makie.Figure object generated by the most recent plotting action in the CasualPlots GUI. Accessible in the REPL for manual inspection or modification.

source
CasualPlots.cp_figure_ax — Constant
cp_figure_ax

The active global Makie.Axis object corresponding to cp_figure. Accessible in the REPL for manual inspection or fine-tuning of plot attributes.

source
CasualPlots.cp_file_df — Constant
cp_file_df

The active global DataFrame loaded from a file (CSV or XLSX) via the Open tab. Accessible in the REPL for inspection or in-place modification (e.g., cp_file_df[5, :col] = ...).

Note: Rebinding cp_file_df = ... in the REPL creates an unrelated variable in Main and does not update the loaded file state. Generated Julia scripts re-read the file from disk and ignore interactive in-place edits.

CasualPlots.@populate — Macro
@populate()

Injects several demo variables into the caller's scope. These variables (prefixed with caspl_) include arrays, matrices, Unitful vectors, and DataFrames of varying complexity. They are primarily used for testing and demonstrating CasualPlots functionality.

Variables created include:

  • caspl_x_10, caspl_ys10, caspl_z10, caspl_2d_sinsin, etc. (Vectors and Matrices)
  • caspl_u_10, caspl_cm_25, etc. (Unitful arrays)
  • caspl_df_simple, caspl_df_large, caspl_df_unitful, etc. (DataFrames)
  • caspl_df_scores (Categorical barplot demo)

CasualPlots.Ele.serve_app — Function
serve_app(app; show=true, frame=true)

Display the app in an Electron window.

Arguments

  • app: The Bonito app to display
  • show::Bool=true: If false, the window is created but hidden (useful for precompilation/testing)
  • frame::Bool=true: If false, creates a frameless window without OS title bar or window controls (useful for screenshots)
