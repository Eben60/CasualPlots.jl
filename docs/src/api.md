# API Reference

## Notes on Programmatic Access to GUI Elements

### State Read-Access via `CasualPlotApp`

The [`casualplots_app`](@ref) function returns a [`CasualPlotApp`](@ref) wrapper struct. This struct holds both the `Bonito.App` instance and the underlying reactive application state (`CasualPlotsState`).

You can inspect the state programmatically from the REPL via `app.state`:

```julia
app = casualplots_app()

# Access selected X and Y variable names
x_var = app.state.data_selection.selected_x[]
y_var = app.state.data_selection.selected_y[]

# Access current plot formatting options
plottype = app.state.plotting.format.selected_plottype[]
```

### Direct Write-Access to Plot Elements and Loaded File Data

The current plot generated by the GUI is exported to the `Main` environment as [`cp_figure`](@ref) (the Makie `Figure` object) and [`cp_figure_ax`](@ref) (the Makie `Axis` object). Similarly, the active `DataFrame` loaded via the **Open** tab is exported as [`cp_file_df`](@ref) for inspection or in-place modification followed by **(Re-)Plot**.

For example, you can modify the plot title directly from the REPL:

```julia
julia> cp_figure_ax.title = "New Title"
```

!!! note
    Modifications made directly to [`cp_figure`](@ref) or [`cp_figure_ax`](@ref), as well as in-place edits made to [`cp_file_df`](@ref), are **not** reflected in the scripts generated by the GUI's "Create Script" functionality (which re-reads the file from disk).
