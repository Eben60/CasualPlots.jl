# Script Generation

`CasualPlots.jl` includes an automatic script generation module that translates the current GUI configuration into standalone Julia code. The generated script operates independently of the CasualPlots GUI, utilizing [`AlgebraOfGraphics.jl`](https://github.com/MakieOrg/AlgebraOfGraphics.jl) and [`WGLMakie.jl`](https://github.com/MakieOrg/Makie.jl) / [`CairoMakie.jl`](https://github.com/MakieOrg/Makie.jl) directly. It uses however some functions provided by `CasualPlots.jl`.

## Purpose

The script generation feature translates an interactive GUI session into a reproducible Julia script. This is particularly useful for:
* **Reproducibility**: Saving the exact configuration of a plot for future reference.
* **Advanced Customization**: Providing a starting point to apply final polishes or customizations not available within the GUI to produce publication-quality plots.
* **Automation**: Integrating the generated code directly into data processing pipelines or larger scripts.

## Generating Code from the GUI
1. Configure your dataset and plot settings in the GUI.
2. Navigate to the **Save** tab.
3. Specify a file path in the **File Path** input field (e.g., `my_plot_script.jl`), or click **Select File...** to browse your filesystem.
4. Click **Create Script** to generate the Julia code and save it directly to the specified file.

---

## Structure of Generated Code

The generated code consists of three main components:

1. **`cp_load_data(...)`**: Extracts and cleans the required data vectors or DataFrames, applying specified row range subsetting.
2. **`cp_create_plot(data)`**: Constructs the `AlgebraOfGraphics` pipeline, sets themes, applies mappings, and returns the figure object.
3. **Execution Block**: Provides commented examples for displaying the figure or saving it to PNG, SVG, or PDF formats using `CairoMakie`.

---

## Example Generated Script

Below is an example of a generated standalone script for a 2D line plot:

```julia
# Auto-generated by CasualPlots.jl
using DataFrames
using WGLMakie
using AlgebraOfGraphics
using CasualPlots

function cp_load_data(; caspl_x_10, caspl_ys10,
    # rows: rows range to plot. Examples: (:begin, :end) (all rows), (1, 100), (:begin, 10), (10, :end)
    rows = (:begin, :end),
    )

    @assert length(rows) == 2 &&
        (rows[1] isa Integer || rows[1] == :begin) &&
        (rows[2] isa Integer || rows[2] == :end)

    # Assuming caspl_x_10 and caspl_ys10 are available in the executing environment
    x_data = caspl_x_10
    y_data = caspl_ys10

    if y_data isa AbstractVector
        y_data = reshape(y_data, :, 1)
    end
    
    n_cols = size(y_data, 2)
    ys = n_cols == 1 ? ["caspl_ys10"] : ["caspl_ys10_$n" for n in 1:n_cols]
    valid_cols = vcat("caspl_x_10", ys)
    df = DataFrame()
    df[!, "caspl_x_10"] = x_data
    for i in 1:n_cols
        df[!, ys[i]] = y_data[:, i]
    end
    df_selected = select(df, valid_cols)

    if rows != (:begin, :end)
        if rows[1] == :begin
            df_selected = df_selected[begin:rows[2], :]
        elseif rows[2] == :end
            df_selected = df_selected[rows[1]:end, :]
        else
            df_selected = df_selected[rows[1]:rows[2], :]
        end
    end

    df_selected = CasualPlots.clean_plot_data!(df_selected, valid_cols)
    return (; df=df_selected, x_name="caspl_x_10", y_name="caspl_ys10")
end

function cp_create_plot(data)
    WGLMakie.activate!() # Or CairoMakie.activate!() for static output

    (; df, x_name, y_name) = data
    ys = names(df)[2:end]
    x_col = Symbol(names(df)[1])
    y_col = :y
    group_col = :group
    df = stack(df, ys; variable_name=:group, value_name=:y)

    final_x_name = "caspl_x_10"
    final_y_name = "caspl_ys10"
    title = "Lines Plot of $final_y_name vs $final_x_name"

    group_mapping = (; color = group_col => "")
    plt = AlgebraOfGraphics.data(df) * mapping(x_col => final_x_name, y_col => final_y_name; group_mapping...) * visual(Lines)
    
    limits = (nothing, nothing, nothing, nothing)
    
    fg = draw(plt; 
        figure=(; size=(800, 600)), 
        legend=(show=true,), 
        axis=(; title, limits, xreversed=false, yreversed=false)
    )
    
    return fg
end
```
