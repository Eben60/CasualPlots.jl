Notes on Programmatic Access to GUI Elements

State Read-Access via CasualPlotApp

The casualplots_app function returns a CasualPlotApp wrapper struct. This struct holds both the Bonito.App instance and the underlying reactive application state (CasualPlotsState).

You can inspect the state programmatically from the REPL via app.state:

app = casualplots_app()

# Access selected X and Y variable names
x_var = app.state.data_selection.selected_x[]
y_var = app.state.data_selection.selected_y[]

# Access current plot formatting options
plottype = app.state.plotting.format.selected_plottype[]

Direct Write-Access to Plot Elements and Loaded File Data

The current plot generated by the GUI is exported to the Main environment as cp_figure (the Makie Figure object) and cp_figure_ax (the Makie Axis object). Similarly, the active DataFrame loaded via the Open tab is exported as cp_file_df for inspection or in-place modification followed by (Re-)Plot.

For example, you can modify the plot title directly from the REPL:

julia> cp_figure_ax.title = "New Title"
Note

Modifications made directly to cp_figure or cp_figure_ax, as well as in-place edits made to cp_file_df, are not reflected in the scripts generated by the GUI's "Create Script" functionality (which re-reads the file from disk).

CasualPlots.cp_file_df — Constant
cp_file_df

The active global DataFrame loaded from a file (CSV or XLSX) via the Open tab. Accessible in the REPL for inspection or in-place modification (e.g., cp_file_df[5, :col] = ...).

Note: Rebinding cp_file_df = ... in the REPL creates an unrelated variable in Main and does not update the loaded file state. Generated Julia scripts re-read the file from disk and ignore interactive in-place edits.

CasualPlots.CasualPlots — Module
Package CasualPlots v0.12.0

CasualPlots aims to provide a graphical user interface (GUI) to simplify the creation of plots in Julia. The tool is positioned in the middle ground between purely script-based plotting and standalone GUI plotting applications.

Usage example:

julia> using CasualPlots
julia> app = casualplots_app()
julia> Ele.serve_app(app) # Open GUI in Electron window

CasualPlots.normalize_numeric_columns! — Method
normalize_numeric_columns!(df, cols)

Normalize numeric columns for plotting compatibility.

For each specified column:

  • AbstractString and Dates.AbstractTime → unchanged
  • Concrete numeric types (Float64, Int, etc.) and Bool → unchanged
  • Abstract Integer subtypes → Int (preserving missing)
  • Abstract Real subtypes → Float64 (preserving missing)
  • Any/unknown types:
    • If >90% of non-missing values are numeric → Float64 (non-numeric become missing)
    • Otherwise → unchanged

Arguments

  • df: DataFrame to normalize
  • cols: Vector of column names to normalize

Returns

(df, dirty_cols) - the modified DataFrame and a vector of column names where non-numeric values were converted to missing.

CasualPlots.skip_rows! — Method
skip_rows!(df, skip_firstrows::UInt, skip_empty_rows::Bool) -> DataFrame

Mutate DataFrame by removing rows:

  1. Delete the first skip_firstrows rows (if > 0)
  2. Delete all rows where every element is missing (if skip_empty_rows is true)

If any rows were deleted and a column's original eltype was not a concrete type (or Union{Missing, ConcreteType}), re-collect the column values to potentially narrow the type.

Returns the mutated DataFrame.

CasualPlots.CasualPlotsState — Type
CasualPlotsState

The top-level reactive state struct for the CasualPlots application. This struct orchestrates all UI observables, separated into logical categories:

  • file_opening: Disk I/O parsing and loaded file paths.
  • file_saving: Output paths and save status.
  • dialogs: Error/Warning modal visibility.
  • data_selection: Array/DataFrame choices and active column selections.
  • plotting: Plot type, formatting options, and Makie figure/axis handles.
  • misc: Internal update flags and cached data.

To inspect this state in the REPL:

app = casualplots_app()
propertynames(app.state)

RESET_FORMAT_OPTION::Dict{String, Set{Symbol}}

  • "never" - Options that persist across all changes (e.g., :plottype)

"range"  => Set([:x_min, :x_max, :y_min, :y_max, :xreversed, :yreversed])
